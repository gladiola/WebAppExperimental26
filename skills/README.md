# Skills to Build WebAppExperimental26 from Scratch

This directory contains seven skill guides covering every capability area needed to build an enterprise-grade ASP.NET Core web application like **WebAppExperimental26** from the ground up.

The skills map directly to the feature areas of the project and reflect the work documented across the pull request history.

---

## How to Use These Guides

Work through the skills roughly in order — each builds on the previous one.  
Skills 5, 6, and 7 can be tackled in any order once you have completed Skills 1–4.

Each guide follows the same structure:

1. **What this skill covers** — a plain-language description of the capability area.
2. **Key concepts** — the core ideas you need to understand.
3. **Prerequisites** — what you should know before starting.
4. **How it applies to this project** — where each concept appears in the codebase.
5. **Learning path** — an ordered sequence of topics to study.
6. **Suggested resources** — documentation, tools, and references.
